# Search, Filters and Navigation

The user-facing English and Tetum pages support partial and mixed-case searches. Search checks scientific name, common name, habitat, identification character, leaf type and fruit type.

Search can be combined with leaf-type and fruit-type filters. Alphabetical sorting applies to the currently filtered results, and Reset clears the search, filters and selected sorting.

The same improvements are included in the web and Android files. The service-worker cache version was updated so the latest search and filter behavior is available after refresh and for supported offline use.
